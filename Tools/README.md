# Tools

## sim_control_loop.c

โปรแกรมจำลองการทำงานของ PID บนคอมพิวเตอร์ (ไม่ต้องต่อบอร์ด)
ใช้ไฟล์ `Core/Src/PID.c` ตัวจริง จึงทดสอบสูตรเดียวกับที่รันบนเครื่อง

**ใช้ทำอะไร**: ลองเปลี่ยนค่า PID แล้วดูว่าเร็วขึ้นไหม แกว่งไหม ก่อนเอาไปลงเครื่องจริง

### วิธีรัน

```bash
gcc -O1 -Wall -I Core/Inc Tools/sim_control_loop.c Core/Src/PID.c -o sim -lm
./sim
```

### สิ่งที่ทดสอบ

| Test | ตรวจอะไร |
|---|---|
| 1 | ป้อนสายระยะต่างๆ ถึงเป้าไหม ใช้เวลาเท่าไหร่ |
| 2 | นับตำแหน่งข้ามรอบ (multi-turn) ถูกไหม |
| 3 | ใบมีดลง-ขึ้น ตามลำดับจริง เลยเป้าไหม |
| 4 | จอดนิ่งแล้วไหลไหม (creep) |
| 5 | มอเตอร์ติดขัด แล้ว integral บวมไหม (anti-windup) |

### ข้อจำกัด

จำลองว่ามอเตอร์ **ไม่ตกขั้น** และ **ไม่มีแรงต้าน** ของจริงจะช้ากว่านี้
ใช้เทียบค่า PID ว่าอันไหนดีกว่ากันได้ แต่ตัวเลขเวลาที่ได้ไม่ใช่ของจริงเป๊ะ
